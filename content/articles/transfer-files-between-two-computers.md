**For a one-off transfer, open a browser-to-browser tool such as Relay on both computers and send the files directly.** It works between any mix of Windows, Mac and Linux, needs nothing installed, and has no size limit. When you're moving a whole system to a new PC, an external drive or the system's own migration tool is better.

## The five ways, compared

| Method | Best for | Speed | Same network needed? |
|---|---|---|---|
| Browser to browser (Relay) | Files and folders of any size, any OS | Fast on the same Wi-Fi | No |
| Network shared folder | Two computers you use every day | Fast | Yes |
| Cloud storage | Files you also want backed up | Slower: uploads, then downloads | No |
| USB drive or SSD | Hundreds of GB, no network | Depends on the drive | No |
| Migration tool (Windows Backup, Migration Assistant) | Moving everything to a new computer | Fast | Varies |

## 1. Browser to browser

1. Open [relay.rishishah.in](/) on the computer with the files and press **Start sending**.
2. Open it on the other computer and tap it under **Nearby**, or type the room code.
3. Drop files or whole folders. Approve and accept, and they stream across, encrypted end to end.

If the Wi-Fi drops, the transfer [resumes from the same byte](/resume-interrupted-file-transfer). On Chrome and Edge large files go straight to disk, so 100 GB is fine.

## 2. Network shared folder

Share a folder from one computer (Windows: right-click › Properties › Sharing; Mac: System Settings › General › Sharing › File Sharing) and open it from the other. Ideal when the same two machines swap files daily. See [Mac and Windows](/transfer-files-between-mac-and-windows) for the exact steps.

## 3. Cloud storage

Put files in OneDrive, Google Drive or Dropbox on one computer and wait for them to sync on the other. Simple, but large files travel twice and use your storage quota.

## 4. USB drive or external SSD

Still the fastest for very large amounts when the network is slow, and it needs no internet. Format the drive as exFAT so both Windows and Mac can read and write it.

## 5. Migration tools for a new computer

- **Windows to Windows:** Windows Backup, then sign in on the new PC to restore.
- **Mac to Mac, or Windows to Mac:** Migration Assistant.

These move apps and settings too, which a file transfer won't.

## FAQ

### How do I transfer files from one laptop to another wirelessly?
Open Relay on both laptops, connect them, and drop the files. On the same Wi-Fi the transfer stays on your local network.

### What is the fastest way to transfer files between computers?
For a few files or folders, a direct transfer on the same Wi-Fi or a cable network. For hundreds of gigabytes, a fast external SSD.

### Can I transfer files between Windows and Linux?
Yes. Relay runs in any browser, so Windows, Mac and Linux all work the same way.
