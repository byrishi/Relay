**The fastest free way to send a large file is to stream it directly to the other device, so there is no upload step and no size limit.** Tools like Relay do this in the browser. If the recipient can't be online at the same time, use a cloud service with a big enough plan.

## Why large files are a problem in the cloud

Cloud transfer services store your file before the other person downloads it, so storage and bandwidth cost them money. That is why free plans have caps:

| Service | Free limit (October 2026) |
|---|---|
| WeTransfer | 10 transfers or 3 GB total per 30 days; links expire after 3 days |
| Google Drive | 15 GB of storage shared with Gmail and Photos |
| Wormhole | Files up to 5 GB stored for 24 hours; larger files go peer-to-peer |
| **Relay** | **No limit, nothing stored** |

You also pay twice in time: a full upload, then a full download.

## Send it directly instead

With a direct transfer the file only crosses the network once, straight to the other device:

1. Open [Relay](/) on both devices and connect them with the room code or QR.
2. Drop the file. The receiver chooses **Save as…** (Chrome and Edge) so it streams straight to disk.
3. Keep both tabs open until it finishes.

On the same Wi-Fi, a direct transfer runs at local network speed, often far faster than your internet upload.

## Tips for really big files (10 GB+)

- **Use Chrome or Edge on the receiving computer.** They write directly to disk, so memory is never the bottleneck.
- **Plug in and stay awake.** Disable sleep on both devices for long transfers.
- **Don't worry about a dropped connection.** Relay [resumes from the exact byte](/resume-interrupted-file-transfer) when the link comes back.
- **Send folders as folders.** Relay keeps the structure; there is no need to zip first. [Sending a folder](/send-a-folder-online).
- **Same network wins.** If both devices are on the same Wi-Fi or Ethernet, the transfer never leaves your building.

## When the cloud is still better

If the recipient will download hours or days later, or many people need the same file, a cloud link is more convenient. Direct transfer needs both devices online at once.

## FAQ

### What is the largest file I can send with Relay?
Relay sets no limit. In Chrome and Edge on desktop, files stream directly to disk, so the only limit is free space. Other browsers keep the file in browser storage first.

### How can I send a 50 GB file for free?
Stream it directly with a peer-to-peer tool like Relay, with the receiver using Chrome or Edge and saving straight to disk. Keep both devices awake until it finishes.

### Is it faster to send large files directly?
Usually yes. A direct transfer crosses the network once, while cloud services need a full upload and then a full download. On the same network it runs at LAN speed.

### What if the transfer is interrupted?
Relay keeps what has arrived and resumes from that point when the connection returns.
