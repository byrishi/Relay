**Most apps cap a single file somewhere between 20 MB and 2 GB.** Email stops at 20 to 25 MB, Discord's free plan at 20 MB, and WhatsApp and Telegram at 2 GB. A direct peer-to-peer transfer such as Relay has no limit, because the file is never uploaded to the app's servers.

## Email

| Service | Send | Receive |
|---|---|---|
| Gmail | 25 MB | 50 MB |
| Outlook.com | 20 MB | 20 MB |
| Yahoo Mail | 25 MB | 25 MB |
| iCloud Mail | 20 MB | 20 MB |
| Proton Mail | 25 MB | 25 MB |

The limit applies to the whole email, and attachments grow by about a third once encoded, so a 20 MB file can already be too big for a 25 MB limit. When a file is over, Gmail swaps in a Google Drive link and Outlook a OneDrive link instead. See [how to email a large file](/email-large-files).

## Chat apps

| App | Free limit per file |
|---|---|
| WhatsApp | 2 GB (sent as a document) |
| Telegram | 2 GB (4 GB with Premium) |
| Discord | 20 MB (50 MB Nitro Basic, 500 MB Nitro) |
| Slack | 1 GB |

WhatsApp compresses photos and videos sent from the gallery. Sending them as a document keeps the original quality. See [sending large videos on WhatsApp](/send-large-videos-on-whatsapp).

## What to do when a file is too big

1. **Both of you online now?** Send it directly with [Relay](/). Open it on both devices, connect with a code or QR, and the file streams across with no cap and no compression.
2. **They'll download later?** Use a cloud link (Google Drive, OneDrive, Dropbox) or an upload site. Compare them in [the best free file transfer sites](/best-free-file-transfer-sites).
3. **Avoid zipping just to shrink it.** Photos and videos are already compressed, so a ZIP barely helps. Zipping is still useful to keep a folder together.

## FAQ

### What is the Gmail attachment size limit?
25 MB per email you send, and up to 50 MB for email you receive. Larger files are shared as a Google Drive link instead.

### What is the WhatsApp file size limit?
2 GB per file when you send it as a document. Photos and videos sent from the gallery are compressed.

### What is Discord's file size limit?
20 MB for free accounts since August 2026, 50 MB with Nitro Basic and 500 MB with Nitro.

### How do I send a file that's bigger than every limit?
Send it peer to peer. Relay has no size limit: Chrome and Edge on a computer even write the file straight to disk, so 50 GB or 100 GB works.
