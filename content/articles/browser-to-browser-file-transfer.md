**Browser-to-browser file transfer lets you send files between any two devices just by opening the same website on both.** No app store, no account, no cable: the file moves directly between the browsers over an encrypted connection.

## Why the browser?

- **Every device has one.** A work laptop where you can't install software, a friend's phone, a school Chromebook: they all have a modern browser.
- **Nothing to trust long-term.** Close the tab and it's gone.
- **Cross-platform by default.** iPhone to Windows, Android to Mac, Linux to iPad: the browser hides the differences.

## How to do it with Relay

1. Open [relay.rishishah.in](/) on both devices.
2. On one, press **Start Transfer**. On the other, type the code, scan the QR code, or tap the device under **Nearby** if you're on the same network.
3. Approve the device, drop or paste your files, and the receiver accepts.

## What works in each browser

| Browser | Send | Receive | Save straight to disk | Send folders |
|---|---|---|---|---|
| Chrome / Edge (desktop) | ✓ | ✓ | ✓ (Save as…) | ✓ |
| Firefox (desktop) | ✓ | ✓ | Saved via browser storage | ✓ |
| Safari (Mac) | ✓ | ✓ | Saved via browser storage | ✓ |
| Chrome (Android) | ✓ | ✓ | Saved via browser storage | Depends on device |
| Safari (iPhone/iPad) | ✓ | ✓ | Saved via browser storage | Not yet |

"Saved via browser storage" means the file is kept in the browser's private storage while it arrives and you press **Save** at the end.

## Tips

- On Android, install Relay from the browser menu (*Install app* or *Add to Home screen*) to get **Share to Relay** in the share sheet.
- Paste a screenshot with Ctrl/⌘+V to send it instantly.
- Keep the tab open (and the phone screen on) until the transfer finishes.

## FAQ

### Do I need an account to transfer files between browsers?
No. Relay has no accounts. You only need the room code or QR code.

### Does browser-to-browser transfer work over mobile data?
Yes. It works over any internet connection. On the same Wi-Fi it is faster because the data stays local.

### Is it safe to transfer files in the browser?
With Relay, yes. The connection is end-to-end encrypted with WebRTC, and you can confirm it with the [safety number](/verify-safety-number).
