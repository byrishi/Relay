**Snapdrop was a much-loved open-source "AirDrop in the browser" for devices on the same network. Snapdrop.net now redirects to PairDrop, a maintained fork.** If you liked Snapdrop, both PairDrop and Relay give you the same instant, no-install sharing; Relay adds internet transfers by code, verification and large-file features.

## What happened to Snapdrop

Snapdrop was created by Robin Linus. The project was later acquired by LimeWire, and the snapdrop.net site has since been replaced by PairDrop.net. The original code remains on GitHub. See [Relay vs PairDrop](/relay-vs-pairdrop) for the fork.

## Snapdrop-style sharing vs Relay

| | Snapdrop (classic) | Relay |
|---|---|---|
| Devices on same network see each other | Yes | Yes (Nearby) |
| Transfers across the internet | No | Yes, with a room code or QR |
| Encryption | WebRTC DTLS | WebRTC DTLS + safety number |
| Approve devices / accept files before transfer | No | Yes |
| Save large files straight to disk | No | Yes (Chrome, Edge) |
| Resume after a dropped connection | No | Yes |
| Send folders with structure | No | Yes |
| Self-hostable | Yes | Yes |

## FAQ

### Is Snapdrop still working?
Snapdrop.net now points to PairDrop. The original open-source code can still be self-hosted.

### What is the best Snapdrop alternative?
For the classic same-network experience, PairDrop. For sending across networks, large files and verified encryption, Relay.
