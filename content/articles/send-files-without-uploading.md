**You can send a file without uploading it anywhere by streaming it directly from your device to the recipient's.** Nothing is stored on a server: the file exists only on the two devices, before and after.

## Upload-and-link vs direct

| | Upload to the cloud | Direct (Relay) |
|---|---|---|
| Steps | Upload, share link, recipient downloads | Connect, send |
| Time | Two full trips | One trip |
| Copy on a server | Yes, until deleted | Never |
| Size cap | Your plan's | None |
| Recipient offline OK | Yes | No |

## Why skip the upload

- **Privacy:** no third party holds a copy that could be breached, scanned or requested.
- **Speed:** the receiver starts getting data immediately; on the same Wi-Fi it never touches the internet.
- **No quotas:** storage limits don't apply to data that's never stored.
- **Nothing to clean up:** no expired links or forgotten shared folders.

## How to do it

Open [Relay](/) on both devices, connect with the code, QR or Nearby, and send. Read [how it works](/how-it-works).

## When uploading is better

If the recipient can't be online at the same time, or you need a link that lasts, cloud storage is the right tool.

## FAQ

### How can I send a file without uploading it?
Use a peer-to-peer tool like Relay that streams the file directly to the other device over an encrypted connection.

### Is sending without uploading safe?
Yes, when the connection is end-to-end encrypted. With Relay you can verify it with a [safety number](/verify-safety-number).

### Do both people need to be online?
Yes. Without a server to hold the file, both devices must be connected during the transfer.
